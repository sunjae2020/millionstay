## 1. 브랜드 정체성

메트하임 여수는 여수 원도심 연등동의 풀옵션 소형 주거입니다.
**"작지만 답답하지 않은, 나만의 프리미엄 도심 생활"** 을 1~2인 가구와 2030 세대에게 제안합니다.

### 브랜드 성격

| 성격 | 의미 |
|---|---|
| **Smart & Compact** | 군더더기 없는 풀옵션 설계. 작은 평형을 넓게 쓰는 효율과 실용을 기본기로. |
| **Urban Premium** | 원도심의 교통·인프라를 그대로 누리는 입지. 호텔 같은 아늑함과 정돈된 품격. |
| **Yeosu Synergy** | 밤바다·등대·별빛. 여수라는 도시의 낭만을 색과 형태로 옮긴 온기. |

### 브랜드 키워드

`아늑한` `스마트한` `감각적인` `신뢰할 수 있는` `도심형` `프리미엄` `여수 밤바다` `나만의 공간`

### 보이스 & 톤

- **말하는 방식** — 담백하고 분명하게. 과장 없이 생활의 편의를 구체적으로. 문장은 짧게, 능동태로. "제출"이 아니라 "예약하기"처럼 사용자가 하는 행동을 그대로 이름 붙입니다.
- **지양** — 모호한 미사여구, 부동산 상투어("초역세권 대박"), 불안 조성형 카피. 상징(별·열쇠·등대)은 은유로만 가볍게, 남발 금지.

> **상징 요약** — 열쇠구멍 = '나만의 안전한 공간', 등대·별 = '집으로 이끄는 불빛', 물결 = '여수 바다'. 카피와 디자인은 이 세 의미에서 벗어나지 않습니다.

## 4. 컬러 사용 비율

**60 · 30 · 10 원칙**을 따릅니다.

```
[■■■■■■■■■■■■ 60% Base ■■■■■■■■■■■■][■■■■■ 30% Teal ■■■■■][■ 7% Gold ■][3%]
```

| 비율 | 색 | 역할 |
|---|---|---|
| **60%** | 크림 · 화이트 · 그레이 | 넓은 바탕. '답답하지 않은' 공간감 |
| **30%** | Urban Teal | 헤더 · 사이드바 · 핵심 면. 브랜드 각인 |
| **7%** | Gold | CTA · 강조선 · 아이콘 |
| **3%** | Soft Brick | 최소 포인트 |

- **랜딩 페이지** — 크림/화이트 비중을 높여 여백을 넉넉히. 티일은 히어로·CTA에 집중, 골드는 버튼·강조 라인에만. 사진이 골드/브릭 역할을 대신할 때가 많음.
- **관리자 페이지** — 티일 사이드바(30%)로 브랜드 고정, 콘텐츠는 그레이/화이트(60%)로 가독성 우선. 골드·브릭은 상태·알림 등 정보 전달에만.

> ⚠️ 골드와 브릭을 넓은 면에 채우지 마세요. 포인트 색이 면적을 차지하면 프리미엄이 아니라 캐주얼·산만함으로 읽힙니다.

## 6. 간격 · 라운드 · 그림자

**4pt 그리드**를 기준으로 간격을 배수로 사용합니다.

- **Spacing 스케일:** `4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96` (px)
- **Radius:** `xs 4` · `sm 6` · `md 10` · `lg 16` · `xl 22` · `pill 999`
- **Elevation(그림자):**
  - `sh-1` — `0 1px 3px rgba(18,35,43,.08)` (카드 기본)
  - `sh-2` — `0 6px 18px rgba(18,35,43,.10)` (호버·팝오버)
  - `sh-3` — `0 18px 44px rgba(18,35,43,.18)` (모달·토스트)

라운드는 부드럽되 과하지 않게, 그림자는 얕고 은은하게 사용합니다.

## 7. 버튼

티일 **Primary**가 기본 행동, 골드 **Accent**는 전환을 유도하는 핵심 CTA에 제한적으로 사용합니다.

### 종류

| Variant | 배경 | 텍스트 | 테두리 | 용도 |
|---|---|---|---|---|
| **Primary** | `#005F73` | `#FFFFFF` | — | 기본 행동 (예약하기) |
| **Accent** | `#C6942E` | `#3A2B08` | — | 핵심 CTA (상담 신청) |
| **Secondary** | 투명 | `#005F73` | `1.5px #005F73` | 보조 행동 (평면도 보기) |
| **Ghost** | 투명 | `#33474F` | — | 낮은 위계 (더 알아보기) |
| **Danger** | `#C24A3A` | `#FFFFFF` | — | 삭제·파괴적 행동 |

### 크기

| 크기 | 패딩 | 폰트 |
|---|---|---|
| Small | 7 / 14 | 13px |
| Medium | 11 / 20 | 15px |
| Large | 15 / 28 | 16px |

### 상태 (State)

| 상태 | Primary | Accent | Secondary |
|---|---|---|---|
| Default | `#005F73` | `#C6942E` | 투명 + 티일 테두리 |
| **Hover** | `#004E5F` + sh-2 | `#A87C1F`, 텍스트 흰색 | 배경 `#E7F0F1` |
| **Active** | `#00323D` | 더 어둡게 | — |
| **Focus** | 포커스 링 `0 0 0 4px rgba(0,95,115,.14)` | 골드 링 | 티일 링 |
| **Disabled** | opacity 0.45, 커서 not-allowed | 동일 | 동일 |

> 한 화면에 Accent(골드) 버튼은 원칙적으로 **하나**. 여러 개가 필요하면 Primary로 위계를 낮춰 시선 분산을 막습니다. 포커스 링은 접근성을 위해 항상 유지합니다.

## 8. 폼 · 입력

라벨은 항상 위에, 포커스는 티일 링으로 명확하게. 오류는 사과하지 않고 **무엇을 어떻게 고칠지** 알려줍니다.

| 요소 | 스펙 |
|---|---|
| Label | 13px / 600 / `#33474F`, 입력창 위 |
| Input | 패딩 11/14, 테두리 `1.5px #C7D0D3`, 라운드 6 |
| Placeholder | `#9FABB0` |
| **Focus** | 테두리 `#005F73` + 링 `0 0 0 4px rgba(0,95,115,.14)` |
| **Error** | 테두리 `#C24A3A` + 하단 도움말 `#C24A3A` |
| **Disabled** | 배경 `#F1F4F4`, 텍스트 `#9FABB0` |

- 오류 예시: *"번호 11자리를 정확히 입력해 주세요."* (원인 + 해결)
- 성공 예시: *"예약이 접수되었습니다. 담당자가 1영업일 내 연락드립니다."*

## 9. 테이블

헤더는 **연회색 음영 + 볼드 + 가운데정렬**, 본문 셀은 **세로 가운데정렬**. 행 호버 시 티일 틴트(`#E7F0F1`)로 하이라이트.

| 요소 | 스펙 |
|---|---|
| 테두리 | `1px #E4E9EA` |
| 헤더 | 배경 `#F1F4F4`, 볼드, 대문자, 가운데정렬 |
| 본문 셀 | 패딩 12/16, 세로 가운데정렬, 좌측정렬 기본 |
| 숫자 열 | 우측정렬 + Mono |
| 상태 열 | 배지로 색 코딩, 가운데정렬 |
| 행 Hover | 배경 `#E7F0F1` |
| Zebra(선택) | 짝수 행 `#F1F4F4` |

**예시 — 호실 관리**

| 호실 | 타입 | 입주자 | 상태 | 월 임대료 | 계약 만료 |

## 11. 랜딩 페이지 스타일

히어로는 밤바다 티일 위 샴페인 카피로 브랜드를 각인하고, 이후 섹션은 크림/화이트로 넓게 비워 정보를 담습니다.

**레이아웃 원칙**

- 넉넉한 여백 · 1단 중심의 스크롤 서사 · 섹션마다 하나의 메시지
- 이미지는 가로로 시원하게, 텍스트는 40자 내외로 끊기
- 히어로: `radial-gradient` 딥 티일 배경 + 샴페인 eyebrow + Accent CTA

**CTA 규칙**

- 화면당 골드(Accent) CTA **1개** 원칙
- 반복 CTA는 Primary(티일)로 낮춰 위계 유지

**히어로 카피 예시**

> ★ PREMIUM URBAN SMALL APARTMENT
> **여수 원도심, 나만의 불빛이 켜지는 곳**
> 연등동 도보권 풀옵션 소형 주거. 짐만 들고 오면 되는 스마트한 하루.
> `[ 입주 상담 신청 ]`  `평면도 보기 →`

## 12. 관리자 페이지 스타일

딥 티일 사이드바로 브랜드를 고정하고, 콘텐츠는 그레이/화이트로 데이터 가독성을 최우선합니다.

| 항목 | 가이드 |
|---|---|
| **레이아웃** | 좌측 고정 사이드바(`#00323D`) + 본문(`#F1F4F4`) |
| **밀도** | 행 높이 44~48px, 셀 패딩 12·16. 정보는 많이, 정렬로 정돈 |
| **색 사용** | 사이드바만 티일. 본문은 무채색 + 상태색. 골드 절제, 브릭은 '주의' 신호에만 |
| **일관성** | 같은 행동은 같은 이름·같은 색. "저장 → 저장됨"처럼 동사 유지 |

**구성 예시:** 사이드바(대시보드·호실·입주자·계약·문의·정산) + 상단 타이틀/액션 버튼 + KPI 카드 3개 + 데이터 테이블

## 13. 이미지 · 아이콘

사진은 '아늑한 도심의 밤'을 향합니다. 여수 밤바다·항구 불빛, 따뜻한 실내, 정돈된 건축 디테일.

### 무드 & 톤 트리트먼트

| 톤 | 컬러 | 쓰임 |
|---|---|---|
| Deep Teal | `#00323D`→`#005F73` | 밤바다 / 야경 |
| Teal→Gold 듀오톤 | `#00323D`→`#C6942E` | 항구 불빛 |
| Champagne | `#E6D5B8`→`#C6942E` | 따뜻한 실내 |

### 촬영·보정

| ✅ 권장 | ❌ 지양 |
|---|---|
| 자연광·저녁 온기, 정돈된 미니멀 공간 | 채도 높은 원색·형광, 어수선한 배경 |
| 건축 라인·질감 클로즈업, 여백 있는 구도 | 과도한 HDR·비네팅, 값싸 보이는 스톡컷 |
| 톤이 튈 땐 티일 오버레이(10~20%)로 통일 | 사람 얼굴 클로즈업 위주 (공간이 주인공) |

### 아이콘

- 라인 아이콘 · 선 굵기 **1.75px** · 둥근 캡/조인 · **24px 그리드**
- 채움은 강조 시에만. 브랜드 모티프(열쇠 · 별 · 물결 · 집)를 우선 활용
