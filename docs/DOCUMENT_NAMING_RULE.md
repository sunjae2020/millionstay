# 문서 파일명 규칙

시스템이 **발행**하는 모든 서류(계약서·인보이스·영수증·견적서·점검표·정산서·
신청서…)는 하나의 규칙으로 이름을 짓는다.

```
<문서코드 3자리>-<이름>_<발행일 YYYYMMDD><순번>.<확장자>

CTR-김용식_20260803A.pdf
INV-김용식_20260803B.pdf
```

- **문서코드** — 종류를 구분하는 3자리 영문. 폴더에서 서류를 훑을 때 이것만
  보고 종류를 안다.
- **이름** — 고객·학생·파트너 등 그 문서의 대상. 사람 이름이 없으면 계정명 →
  건물/호실명 순으로 대체하고, 그것도 없으면 `미지정`.
- **발행일** — 문서 자체의 날짜(인보이스 발행일, 수납일, 계약 작성일…). 렌더
  시점이 아니다.
- **순번** — 같은 사람에게 같은 날 나간 문서를 구분한다. `A`…`Z` 다음은
  `A1`…`Z1` … `A9`…`Z9`로, 사람·일자당 260건.

## 순번은 사람+날짜 기준이다

문서 종류와 **무관하게** 이어진다. 같은 사람에게 같은 날 계약서와 인보이스를
발행하면 `CTR-…A`, `INV-…B`가 되어 파일명이 전체에서 겹치지 않는다.

## 문서코드

| 코드 | 문서 | `DocKind` |
| --- | --- | --- |
| CTR | 계약서 | `contract` |
| SGN | 전자서명 완료본 | `signed_contract` |
| INV | 인보이스 / 세금계산서 | `invoice` |
| RCP | 영수증 | `receipt` |
| QUO | 견적서 | `quote` |
| INS | 세대점검표 | `inspection` |
| STL | 보증금 정산 / 퇴거 세대 확인서 | `settlement` |
| APL | 신청서 | `application` |
| WOR | 작업지시서 | `work_order` |
| BRF | 서비스 브리프 | `brief` |
| RPT | 리포트 | `report` |
| SMP | 서식 샘플 / 빈 양식 | `sample` |
| DOC | 그 외 | `other` |

새 문서를 추가할 때는 [artifacts/api-server/src/lib/documents/filename.ts](../artifacts/api-server/src/lib/documents/filename.ts)의
`DOC_CODES`에 코드를 먼저 등록한다.

## 구현 규칙

- 이름은 `issueDocumentFilename()` **하나로만** 만든다. 라우트에서
  `` `${ref}.pdf` `` 같은 문자열을 직접 조립하지 않는다.
- PDF 응답은 `setDocumentDownloadHeaders(res, filename)`으로 헤더를 세운다.
  한글이 들어가므로 `Content-Disposition`은 RFC 5987 형식이 필수이고, 프론트가
  blob으로 받아 저장할 수 있도록 `Access-Control-Expose-Headers`로 노출한다.
- 프론트(`DocumentPreviewDialog`)는 이 헤더가 있으면 그것을 다운로드 이름으로
  쓴다. 호출부의 `filename`은 헤더가 없을 때의 폴백일 뿐이다.
- **이름은 문서당 한 번만 정해진다.** PDF는 미리보기·다운로드·이메일마다 다시
  렌더되므로 매번 순번을 새로 뽑으면 같은 인보이스가 A였다가 B가 된다. 최초
  발행 시 `document_file_names`(마이그레이션 0039)에 기록하고 이후에는 읽어 쓴다.

## 적용 범위

- **적용** — 서버가 렌더해 내보내는 모든 문서(미리보기/다운로드/이메일 첨부),
  그리고 발행본 스냅샷(`freezeDocument` → `…-v2.pdf`).
- **미적용** — 사무실에서 업로드한 스캔본·회사 서류. 받은 파일의 원래 이름이
  곧 추적 단서라 그대로 둔다. 대신 업로드 인박스의 파일명 판독기
  (`intakeScan.ts`)가 이 규칙을 알고 있어서, 우리가 발행했다가 서명받아 다시
  올라온 문서는 코드·이름·날짜를 바로 읽어낸다.
- 서식 샘플·빈 양식은 발행 대상이 없으므로 순번을 소비하지 않는다
  (`SMP-<서식키>_<locale>`).
