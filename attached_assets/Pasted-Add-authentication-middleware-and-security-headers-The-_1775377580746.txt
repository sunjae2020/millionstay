1. SESSION-BASED AUTH MIDDLEWARE
════════════════════════════════════════
Create server/middleware/requireAuth.ts:

import { Request, Response, NextFunction } from 'express';

export function requireAuth(
  req: Request,
  res: Response,
  next: NextFunction
) {
  // Check session (express-session)
  if (req.session && (req.session as any).userId) {
    return next();
  }
  // Check Bearer token (JWT fallback)
  const auth = req.headers.authorization;
  if (auth?.startsWith('Bearer ')) {
    const token = auth.slice(7);
    try {
      const payload = verifyJWT(token); // your existing verify fn
      (req as any).user = payload;
      return next();
    } catch {
      // fall through to 401
    }
  }
  return res.status(401).json({
    success: false,
    error: { code: 'UNAUTHORIZED',
             message: 'Authentication required' }
  });
}

Apply to ALL API routes EXCEPT:
  POST /api/v1/auth/login
  GET  /api/v1/health
  GET  /api/v1/public/*  (future landing page)

In server/index.ts, apply globally:
  import { requireAuth } from './middleware/requireAuth';
  app.use('/api/v1', requireAuth);
  app.use('/api/v1/auth', authRouter);  // exempt login
  app.use('/api/v1/health', healthRouter); // exempt health

2. LOGIN ENDPOINT
════════════════════════════════════════
If POST /api/v1/auth/login returns 404, create it:

POST /api/v1/auth/login
Body: { email: string, password: string }

Logic:
  1. Find user by email in users/user_accounts table
  2. Compare password hash (bcrypt.compare)
  3. If valid:
     - Set req.session.userId = user.id
     - Generate JWT: sign({ id, email, role }, SECRET, { expiresIn: '8h' })
     - Return { success: true, token, user: { id, email, role } }
  4. If invalid:
     - Log failed attempt to system_log
     - Return 401: { success: false, error: "Invalid credentials" }

POST /api/v1/auth/logout
  - Destroy session
  - Return { success: true }

GET /api/v1/auth/me
  - Return current user from session/JWT
