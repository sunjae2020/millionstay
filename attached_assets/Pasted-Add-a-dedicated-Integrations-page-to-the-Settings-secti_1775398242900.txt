  3. Resend Email
  4. Maps
  5. OTA / iCal Sync
  6. AI Chatbot (Coming Soon)

Each card:

  - Status badge:
      green "Connected"
      amber "Test Mode"

      gray  "Not Configured"

  - [Test Connection] button

════════════════════════════════════════
SECURE KEY DISPLAY
════════════════════════════════════════
API keys must be masked by default:
  sk_test_xxxx...xxxx (show first 8 + last 4 only)
  [👁 Show] button to reveal full key (admin only)
  [📋 Copy] button

Keys are read from environment variables.
Saving from UI updates the env vars via:
  POST /api/v1/integrations/update-env
  body: { key: 'STRIPE_SECRET_KEY', value: 'sk_...' }
  → updates process.env AND writes to .env file
  SECURITY: This endpoint requires SuperAdmin role
